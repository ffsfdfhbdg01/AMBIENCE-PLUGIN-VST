SAMS AMBIENCE CONTROL

Psychoacoustic distance, direction and obstacle simulation for film mixing.
Psychoakustyczna symulacja odległości, kierunku i przeszkód do miksu filmowego.

Installation location / Lokalizacja instalacji

  • Install for all users (default / domyślnie): /Library/Audio/Plug-Ins/VST3, /Library/Audio/Plug-Ins/Components, /Applications
  • Install for me only / tylko dla mnie: ~/Library/Audio/Plug-Ins/…, ~/Applications

Choose the destination on the Destination Select step and the formats (VST3 / AU / Standalone) under Customize.
Miejsce wybierzesz w kroku Wybór miejsca docelowego, a formaty w Dostosuj.
